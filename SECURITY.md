# Security Policy

If you discover a security issue in CAuth, please do not open a public issue with full exploit
details.

Use a private reporting channel controlled by the project maintainer, or GitHub private
vulnerability reporting if it is enabled for the repository.

Until a dedicated security contact is published, treat the repository as not accepting public
full-disclosure reports before maintainer review.

## Scope

Security-sensitive areas include:

- credential storage
- refresh/access/session token handling
- password handling
- logging and redaction behavior
- cloud/depot authorization materials

Additional project notes live in [docs/security.md](docs/security.md).
